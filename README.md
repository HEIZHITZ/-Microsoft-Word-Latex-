# -Microsoft-Word-Latex-
通过Microsoft Word文档自动处理Latex公式

文档中公式应符合 $Latex$ 的格式，且$...$之间不应存在换行符

Formulas in the document should follow $Latex$ format, and there should be no line breaks between $...$.

复制绝对路径，会自动另存为修改好的文件

Copying the absolute path will automatically save it as the edited file.
